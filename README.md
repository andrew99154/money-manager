# Money Manager - 記帳小幫手
使用 Kotlin 製作的 Android 記帳 app, 提供簡單直觀的介面，幫助使用者追蹤支出情形。

A bookkeeping app built by Kotlin, simplifies expense tracking with an intuitive interface, offering features like expense categorization and reporting.
